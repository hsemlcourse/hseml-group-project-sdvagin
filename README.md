## Описание задачи

**Задача:** Бинарная классификация. Предсказание того, откроет ли клиент банка срочный депозит на основе социально-демографических данных, макроэкономических показателей и истории предыдущих контактов маркетинговой кампании.

**Датасет:** [Bank Marketing Dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing) из открытого репозитория UCI Machine Learning. Датасет монетарного типа.

**Целевая метрика:** Основной метрикой качества выбрана **F1-score**, дополнительной — **ROC-AUC**.  
*Обоснование:* В данных присутствует сильный дисбаланс классов (около 89% отказов и 11% согласий). Классическая метрика ROC-AUC в таких условиях дает слишком оптимистичную оценку. F1-score (гармоническое среднее между Precision и Recall) позволяет объективно оценить способность модели находить редкий класс, минимизируя как ложные срабатывания, так и пропуски целевых клиентов.

## Результаты
Сравнение базового решения и финальной модели. Основной упор делался на метрику F1 из-за сильного дисбаланса классов.

| Модель | F1-Score | ROC-AUC | Примечание |
|--------|----------|---------|------------|
| Baseline | 0.6013 | 0.9403 | Logistic Regression (class_weight='balanced') без подбора параметров |
